# El escritorio de Cami

Portafolio de Camilo Gómez Forero. Página estática: `index.html` en la raíz, más `img/`, `fotos/`, `shots/`, `video/` y `audio/`.

Para recibir los mensajes del aro en el correo, pega el endpoint de Formspree en `FORM_ENDPOINT`, al inicio del script de `index.html`.

## Actualizaciones (19 nov. 2026)
